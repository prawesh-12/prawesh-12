## 👽 some cool stuff i built :)

- 🤖 **[syncPilot](https://github.com/prawesh-12/sync-pilot)** - an Ai agent for your inbox. It reads every new Emails, works out what it needs and sends you a brief on Signal app, where you can approve the draft, send it or ask for a rewrite.
- 🦀 **[elanprint-rs](https://github.com/prawesh-12/elanprint-rs)** - a fingerprint sensor driver written in pure Rust, running entirely in userspace. I reverse engineered the vendor's USB protocol and exposed it through `fprintd` over D-Bus, so PAM and the lock screen just work.
- 🧠 **[quizLoom](https://github.com/prawesh-12/quizloom)** - a platform for running live exams, with authoring, proctoring, live monitoring and analytics.
- ⚙️ **[serveInfer](https://github.com/prawesh-12/serveInfer)** - an LLM inference runtime that serves GGUF models on a single machine. It spreads the work across processes, schedules the requests, falls back when the hardware fails, recovers from crashes and streams the answer back over HTTP and SSE.
- 🕸️ **[jaal](https://github.com/prawesh-12/jaal)** - an ML powered fraud detection engine for identifying coordinated accounts involved in promotional coupon and discount code abuse.
